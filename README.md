# SprigLink

A private URL shortener you run on your own server. One admin, no public form where strangers can add links, no framework, and no Composer.

The program and this README were generated by Grok, built by xAI.

Short links look like `https://example.com/?c=abc123`. That shape works as soon as `index.php` is the page the server opens for the folder. You do not need a rewrite rule.

## What you need

- A host that runs PHP 8.0 or newer. Most shared hosting does.
- The SQLite part of PHP (`pdo_sqlite`). It is included with PHP.
- `curl` is optional. SprigLink only uses it to look up where a public IP address is.

You do not install a database server. SprigLink keeps everything in one file.

## Install

1. Upload this whole folder so that `index.php` is directly inside the website folder. On shared hosting that folder is often named `public_html`.

2. Open `index.php` in a text editor. Near the top are two lines you can change:
   - `$spriglinkConfigFile` is the file with the sign-in password. By default that is `config.php` in this same folder.
   - `$spriglinkDatabaseFile` is the database. By default that is `data/spriglink.sqlite`.
   If the host lets you store files outside the website, point both lines at that private folder. Visitors then cannot download them even if something else is misconfigured. If you leave the defaults, the `.htaccess` file next to `index.php` blocks those downloads on Apache. On nginx, copy the deny rules from `examples/nginx.conf.example` and do not remove them.

3. Open `config.php` and change the username and password. The ones that ship with the app are `admin` and `change-this-password`. Change both before anyone else can reach the site. If you don't change them, they are displayed on the login page as a reminder.

4. In a browser, open `index.php?page=login` and sign in.

The first visit creates the database file. The web server has to be allowed to write to that folder.

After you sign in, open Settings. That page is where you can set the public address, timezone, length of generated codes, location lookup, whether destination sites can see the short link, and the API token. You do not need to edit those by hand. The sign-in password stays in `config.php`.

A normal short link looks like `https://your-host/?c=abc123`. The admin page is `https://your-host/index.php?page=admin`. If the app lives in a subfolder, both addresses include that folder on their own.

If copied links show the wrong host or say `http` when the site is `https`, set the public address in Settings.

### A small nginx site

The website folder is the one that contains `index.php`.

```nginx
root /var/www/spriglink;
index index.php;

location ~ ^/(app|templates|data|examples|tests)/ { deny all; }
location = /config.php { deny all; }
location = /router.php { deny all; }
location ~* \.(sqlite3?|db)(-wal|-shm)?$ { deny all; }

location ~ \.php$ {
    include fastcgi_params;
    fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    fastcgi_pass unix:/run/php/php8.3-fpm.sock;
}
```

### Optional friendly links

`https://your-host/abc123` only works after the web server sends unknown paths to `index.php`. Normal `/?c=` links keep working either way. In Settings, choose **Friendly** after the rule is in place. `pretty_urls` in `config.php` is only the starting value, before you save that choice.

**NGINX.** Inside `server { }`, find the block that starts with `location ~ \.php$`. Paste the block below **above** that PHP block. The new block comes first. The PHP block stays after it. Keep the deny blocks. Then run `sudo nginx -t && sudo systemctl reload nginx`.

```nginx
location / {
    try_files $uri $uri/ /index.php?$query_string;
}
```

**Apache.** The `.htaccess` next to `index.php` already blocks private files. Turn on `mod_rewrite`, allow `AllowOverride FileInfo`, and add the rules in `examples/apache-htaccess.txt` **under** those deny rules. Do not replace the file.

```apache
<IfModule mod_rewrite.c>
    RewriteEngine On
    RewriteBase /
    RewriteCond %{REQUEST_FILENAME} !-f
    RewriteCond %{REQUEST_FILENAME} !-d
    RewriteRule ^ index.php [L]
</IfModule>
```

You can also find these instructions on the settings page.


## What you can do

- Random codes, or a code you type. Ambiguous characters `0`, `O`, `1`, `l`, and `I` are left out of random codes.
- Expiry: 1 hour, 1 day, 7 days, 30 days, 90 days, or a specific date. Times use the timezone in Settings.
- Click limit. The limit counts every recorded visit, including bots. Settings can clear visit details without changing those counts, or reset the counts so limits start over. The links stay.
- Optional password before the redirect. A correct password is remembered for 12 hours in a cookie.
- Mark a link private so it stays off the homepage. Anything not marked private is listed there with its short URL and its full URL.
- Settings can turn that homepage list off. The choice is stored in the database and overrides `show_public_links` in `config.php`.
- Immediate redirect, or a preview page that shows the destination first.
- 302 by default so browsers do not cache the hop and skip your stats. 301 is available per link.
- Turn a link off without deleting it.
- Renaming a code can keep the old code as an alias.
- Stats: total and unique visits, last 30 days, browser, OS, device, language, referrer, and place.
- Bots and link-preview crawlers are stored and hidden from the default charts.
- If location lookup is on (Settings), public IPs are resolved via ip-api.com when you open the dashboard or a stats page. Private addresses stay labeled "Private network". Behind Cloudflare, `CF-IPCountry` is saved at click time.
- CSV export for one link or every link.
- Delete a link and its stats.
- Optional JSON API. Set the token in Settings. Leave it blank to keep the API off.

## API

```bash
curl -s -X POST https://your-host/index.php?page=api \
  -H 'Content-Type: application/json' \
  -d '{"token":"your-token","url":"https://example.com/long","code":"notes","expires_in":"30d"}'
```

`expires_in` may be `never`, `1h`, `1d`, `7d`, `30d`, `90d`, `YYYY-MM-DD`, or `YYYY-MM-DDTHH:MM` in the configured timezone. `code` may be omitted. Also accepted: `title`, `notes`, `click_limit`, `password`, `redirect_mode` (`instant` or `preview`), `status_code` (`301` or `302`), `private` (`true` to keep the link off the homepage).

## Password storage

`admin_password` may be the password itself, or a hash from:

```bash
php -r "echo password_hash('a strong password', PASSWORD_DEFAULT), PHP_EOL;"
```

Hashes start with `$2y$` or `$argon2`. Eight failed sign-ins from one IP lock that IP out for 15 minutes.

## Layout

```
index.php           website entry. Two path variables at the top.
config.php          password and settings. Move it with $spriglinkConfigFile.
data/               database, unless $spriglinkDatabaseFile points elsewhere
assets/             styles, script, fonts
app/                program code, blocked from download
templates/          page markup, blocked from download
examples/           nginx and Apache samples, blocked from download
.htaccess           Apache rules that block the private files
router.php          used by PHP's built-in server only
```

`trust_proxy` must stay false unless nginx is the only way in and it sets `X-Forwarded-For` and `X-Forwarded-Proto`. Turning it on at the origin lets a client spoof their IP.
